## 3 功能与修复（按任务）

### 3.1 云端登录验收中当场修复（11-08）
- **C1 云端缺少参考数据**：没有技能、行业、职能领域数据。在云端执行 `load_initial_data`，部署脚本的结束提示也改为要求执行它。
- **C2 新环境中学生无法添加教育经历**：学位表为空。`load_gradbridge_reference_data` 新增 173 个学位、41 所新加坡和澳大利亚院校。
- **C3 链接指向上游**：页脚和登录页的链接、canonical 地址还指向 peeljobs.com，改为配置的地址。
- **C4 示例文字仍是印度习惯**：期望薪资和成绩示例改为本地习惯（WAM、GPA）。
- **C5 时间显示不一致**：发布时间不带时区，同一行显示的两个时间看起来相差 3 小时。现在带上服务器的时区偏移。
- 验收的 17 步覆盖：资料、技能、教育 → 连接 RR → 草稿 → 编辑 → PDF（中文字体正常）→ 发布 → HR 组合筛选、下载（哈希与学生端一致）、收藏和备注 → 学生只改草稿时 HR 仍看到 v1 → 撤回后 HR 看到 404 → 再次发布 v2 → 断开 → 重新连接 → 退出。

### 3.2 S4-01 品牌与文案（26f31e1，109 个文件）
- 两个前端、邮件、API 文档中的 “PeelJobs” 全部改为 “GradBridge”，并启用新标志。
- 删除编造的数字和说法：50K+ 职位、1M+ 求职者、95% 成功率、竞品对比、“AI 匹配”、“所有公司已认证”等。
- 分类改用本地叫法：Fresher → Graduate，Walk-in → Open Day(s)，Government → Public Sector。迁移 0088 只改选项名称，存储的值不变。
- 删除上游的联系方式，只保留联系表单。

### 3.3 S4-04 小修复（91973fc）
- 两个前端共 9 处浏览器原生 `confirm()` 改为页面内确认框。原生对话框会被部分内嵌浏览器自动取消，导致发布被悄悄取消。
- 草稿名称带时区缩写；主手机号和备用手机号使用同样的格式和校验；集成页不再先闪一下 UTC 时间。

### 3.4 S4-05 频率限制（c0c5312）
- 登录、找回密码、重发验证邮件按目标邮箱计数（缓存中只存哈希）；注册和联系表单设全站总量上限。计数存放在数据库缓存表中（迁移 0089），多个进程共用。
- 云端验证：连续 6 次请求，第 6 次返回 429。
- RR 的动态客户端注册保留上游做法，剩余风险写进部署手册 11.2（风险 R13）。
- 11-09 按 PM 决定放宽（风险 R11）：登录改为每个邮箱每分钟 10 次，找回密码和重发验证邮件改为每小时 10 次。

### 3.5 S4-02 发信（a61b479）
- 新增 `backend/jobsp/acs_email.py`：用连接串签名，直接调用 ACS REST 接口，没有新增依赖。
- 开通 `gradbridge-email`（Azure 托管域名，发件人 DoNotReply@…azurecomm.net，显示名 GradBridge）和 `gradbridge-acs`，数据位置 Australia。
- 11-09 实测：团队邀请邮件和注册验证邮件约 15 秒到达 Gmail 收件箱，没有进垃圾箱。

### 3.6 S4-03 演示数据与职位链接（701ef92、3f39ff6、167256c）
- `load_gradbridge_demo_data [--remove]`：8 家 “(Demo)” 公司、40 个职位，每家公司只在一个国家招聘（新加坡用 SGD，澳大利亚用 AUD）。职位文字写明不是真实职位；所属的招聘方账号无法登录，也没有联系方式。
- **缺陷**：从职位列表点进详情页是 404，原因是招聘方新建的职位存的是不带斜杠、可能重复的 slug。新增 `JobPost.public_slug()`，详情接口兼容旧的 slug。

### 3.7 S4-07 Key Vault 与云端恢复演练（7881545）
- 新建 Key Vault `gradbridge-kv-53888c`（RBAC 模式）。`deploy.ps1 -KeyVault` 把 8 个密钥写入 Key Vault，应用里只保存引用；部署日志中密钥出现 0 次。
- 数据库时间点恢复到新服务器用时 9 分钟，各表行数一致。发现恢复出来的服务器没有防火墙规则，已写进手册。演练服务器用完后已删除。
- 两个文件共享各做了一次快照，逐个文件核对一致。

### 3.8 S4-08 监控（35e38a5）
- Application Insights `gradbridge-insights`：api、rr、site 三个标准可用性测试，每 15 分钟一次，从澳大利亚东部和东南亚发起。
- 告警 `gradbridge-availability` 发给订阅 Owner。11-09 实测：停 api 后 13 分钟收到告警邮件。
- 费用约每月 7 美元。

### 3.9 S4-06 云端隔离验收与两个缺陷（a610ccb、43f2e72）
- 用户注册了 HR2（通过邀请加入 2hr 所在的公司）和 HR3（另一家公司）。
- 检查结果：
  - HR2 看不到 2hr 的收藏和备注；
  - HR3 看不到其他公司的成员，直接打开对方成员页返回 404；
  - 学生账号登录招聘端被拒绝；
  - 候选人池只包含已发布简历的学生。
- **缺陷 1**：被邀请的成员无法加入。表单跳过了设置密码的步骤，提交时提示 “Please fill in all required fields”。
- **缺陷 2**：招聘端 Logout 没有反应。菜单关闭时把退出表单从页面上移除了，浏览器于是取消了这次提交。顺带补上公司用户侧栏缺少的 Account。
- 这两个都是上游代码中原有的问题，都已修复、部署并合并（PR #2）。
